# Bing Search Bot 🔎

Projeto simples de automação web desenvolvido com Python e Selenium.

## 🚀 Funcionalidades

- Abre o Bing automaticamente
- Aceita cookies automaticamente
- Realiza pesquisas
- Captura títulos dos resultados
- Navega para a próxima página
- Exibe os resultados no console

## 🛠️ Tecnologias utilizadas

- Python
- Selenium
- ChromeDriver

## ▶️ Como executar

Instale o Selenium:

```bash
pip install selenium
```

Execute o projeto:

```bash
python main.py
```
