# Google Search Bot

Automação desenvolvida com Python e Selenium para realizar pesquisas no Google e coletar resultados automaticamente.

## 🚀 Tecnologias
- Python
- Selenium

## 📚 Objetivo
Projeto criado para estudos de automação web com Python.

## ▶️ Como executar

```bash
pip install -r requirements.txt
python main.py
```
